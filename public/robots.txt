# Standalone Google/Bing Ads site, served on finanshelsaccounting.co and on the
# older accounting.finanshels.co. Nothing here is meant for organic search, so
# every page carries a noindex — see the X-Robots-Tag header in vercel.json, the
# meta tag in index.html and the runtime tag in src/components/Seo.jsx.
#
# Crawling by SEARCH engines is deliberately ALLOWED. A crawler blocked here
# never reads the noindex, and can still list a bare URL it found linked
# somewhere else. Letting bots in to read the noindex is what actually keeps the
# site out of the index. AI/LLM crawlers are a different case and are blocked
# outright at the bottom of this file.
#
# Ad crawlers must never be blocked or the ads get disapproved for an
# unreachable destination. They are listed explicitly so that adding a
# "Disallow: /" later cannot take the campaigns down with it.

User-agent: *
Allow: /

# Google Ads landing page crawler
User-agent: AdsBot-Google
Allow: /

User-agent: AdsBot-Google-Mobile
Allow: /

# Microsoft Advertising landing page crawler
User-agent: adidxbot
Allow: /

# ---------------------------------------------------------------------------
# AI / LLM training and answer-engine crawlers are blocked outright. They have
# no bearing on ad serving, they ignore noindex (a search-index directive, not a
# training one), and anything they ingest here can resurface as an answer that
# ties this ads site to the wider Finanshels web presence — exactly the
# association these campaigns must not carry. See also /llms.txt.
# ---------------------------------------------------------------------------
